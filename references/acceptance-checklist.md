# 主 Agent 验收清单

全部 worker 返回后，逐项执行。任何一项失败 → 打回对应 worker 重修，修不到绿不得汇报完成。

## 1. 文件落盘复查（不信自报）

- [ ] 列出各 worker 目录下实际文件（find/Glob），与回报清单逐一对上
- [ ] 抽查关键文件内容非空、结构合理（Read 抽样）
- [ ] 报告缺失/多余文件并追问

## 2. 验证命令真跑（不信"应该通过"）

- [ ] 按各任务书的验收命令在对应目录实际执行（Bash/PowerShell）
- [ ] 核对退出码与期望输出（测试全绿 / lint 无错 / 脚本输出符合预期）
- [ ] 保存关键输出原文，汇报时引用

## 3. 边界检查（无越界写入）

- [ ] 确认 worker 目录之外无新增/被改文件（对照派发前状态）
- [ ] 确认未合并 main、未 force-push、共享依赖未被改动
- [ ] 发现越界 → 打回恢复并重做

## 4. 整体集成复验

- [ ] 各包产物按契约组装后整体再跑一遍核心检查（端到端冒烟 / 全量测试）
- [ ] 接口对齐：包间调用与契约一致（字段、格式、路径）
- [ ] 有冲突先解冲突再复验

## 5. 汇报格式

汇报给用户时固定结构：

```
## 演示/任务完成情况
| worker | 任务 | 产出 | 验证结果 |
|---|---|---|---|
| worker-a | ... | 文件清单 | 命令结果原文摘要 |

集成验证：<整体复验结果>
遗留问题：<无 / 如实列出>
```

- 有交付文件时用运行环境的产物呈现方式呈上（如文件预览/交付卡片）。
- 失败、卡住、未达验收如实标注，不掩盖、不谎报。
